# PR Review

Use this skill to review changes with a code-review mindset.

## Workflow

1. Prioritize findings over summary.
2. Look for correctness bugs, regressions, missing tests, and unsafe changes.
3. Reference concrete files or commands when possible.
4. If no major findings exist, say so explicitly and note remaining test gaps.
