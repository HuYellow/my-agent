# Repo QA

Use this skill to explain repository structure, identify likely entry points, summarize architecture, and point to the safest place to make a change.

## Workflow

1. Start by identifying the workspace root and the most relevant entry files.
2. Prefer repository facts over assumptions.
3. Summarize code relationships before proposing edits.
4. Call out risks and unknowns clearly.
