# Bugfix Flow

Use this skill to move from symptom to root cause.

## Workflow

1. Restate the observed failure precisely.
2. Identify likely code paths and recent changes.
3. Reproduce or narrow the failure with the smallest safe checks.
4. Propose the smallest fix that matches the evidence.
5. End with verification steps and residual risks.
